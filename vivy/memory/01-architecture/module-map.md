# Module Map

- `problem_compiler`: chuẩn hóa mục tiêu, constraint và unknowns.
- `hypothesis_population`: sinh và quản lý ThoughtState.
- `thought_ecology`: dependency, contradiction, overlap.
- `adaptive_n`: quyết định branch/merge/prune và ngân sách N.
- `experiment_designer`: chọn phép thử theo information gain/cost.
- `contract_generator`: tạo contract chuẩn hóa.
- `executor_router`: chọn local model, solver, tool hoặc human.
- `evidence_assimilator`: chuẩn hóa evidence và provenance.
- `verification_tribunal`: cross-check, reproduce, calibrate.
- `state_update`: cập nhật đồng thời các ThoughtState.
- `memory`: quản trị memory phân tầng.
- `codegraph`: lập chỉ mục repository và impact.
