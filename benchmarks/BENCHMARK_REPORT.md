# Vivy-V Release Summary

**`Vivy-V`** is the upgraded generation featuring an **optimized thinking core**, open-source model weights (`.gguf` / `.safetensors` + `Modelfile`), and an encrypted proprietary `Vivy-V` architecture (`.vcore`).

All prior `Vivy.v6` benchmark editions are archived as `[ARCHIVED_LEGACY_VIVY_V6]`.
