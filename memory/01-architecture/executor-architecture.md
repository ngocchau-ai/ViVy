# Executor Architecture

Local Software Department:

- Local Architect
- Local Coder
- Local Test Engineer
- Local Code Reviewer
- Local Security Reviewer
- Local Performance Analyst
- Local Documentation Builder

Một model có thể kiêm nhiều vai trò ở giai đoạn đầu, nhưng mỗi lần chạy phải dùng role contract riêng. Model viết code không được là nguồn xác nhận duy nhất cho chính code đó.
