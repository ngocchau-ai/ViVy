## 1. Core Mechanics

Warp Divergence: threads in a 32-thread warp take different branches. All paths execute serially. Minimize by reducing if/else in kernels.

## 2. Hard Invariants

- A warp is 32 threads (SIMT). - Divergence penalty = sum of branch paths. - __syncwarp() mandatory after warp-level primitives.

## 3. Verified API Signatures

```cuda
__ballot_sync(mask, pred)
__shfl_sync(mask, var, srcLane)
__syncwarp(mask)
```

## 4. Known Gotchas

- Avoid branch divergence in inner loops. - Use warpSize constant, not literal 32. - __syncwarp() does NOT sync across warps.
